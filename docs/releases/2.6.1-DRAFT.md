# Elsepin 2.6.1 — Appearance, routes and search

Unpublished draft. Build 63 passed native validation and is in Downloads for testing. No release asset is attached; public 2.6.0 remains unchanged. Device crash fixes, layout and third-party speed readings still need acceptance.

## Changes
- General keyboard Search now shows matching places with addresses instead of silently choosing the first result. Keep explicit selection and movement confirmation.
- Harden route-hold/jump interactions with native map touch coordinates, matching route-index guards and interruption cleanup.
- Account for smooth acceleration/corner slowing in simulated duration. Show Apple Maps travel time separately where available.
- Pace updates using successful confirmations and recent write latency, avoiding immediate catch-up bursts after slow responses. Life360 computes its own speed; its MPH is not guaranteed.
- Make route name, distance, ETA and progress easier to scan in the Live Activity. Retain short update status, independent provider checks, stale warnings and pairing-code privacy.
- Simplify on-device pairing to three connected steps in task order; remove the Pairing help section. Use the selected theme and existing button feedback throughout the sheet.
- Keep all five draft travel modes visible in a wrapping grid, with a flexible single column for accessibility text sizes.
- During on-device setup, show pairing progress and the generated code in Elsepin's existing Live Activity. Touch and hold the Dynamic Island to read it over iPhone Settings; notifications and the app remain fallbacks. Clear the code after completion/cancellation and hide stale codes.
- Bloom is the default theme for new installs and resets.
- Remove Abyss from theme choices; existing Abyss selections and backups migrate to Bloom. Other saved themes remain selected.
- Use rounded fonts and compact relative text sizing across the app's shared appearance presentation. Accessibility text categories remain unchanged.
- Remove font, text-size and color-mode controls. Themes determine color mode; surface choices are Solid (the default) and Liquid Glass. Legacy Theme default values migrate to Solid.
- Preserve all thirteen icons and all existing Elsepin features; no paid edition restrictions.
- Keep old backup formats and import/export: routes, saved places, areas and supported settings remain usable. Retired typography/color fields decode but cannot override fixed appearance. Exports retain rounded/compact fields for older versions.
- Update the website catalog source to eight themes and rounded previews; no deployment.

- Keep Settings search swipe-revealed with a compact title and separated scroll content; device confirmation of the reported overlap fix remains pending.

- Compact Settings layout with the larger “MAKE IT YOURS / Your space. Your way.” identity card retained, no duplicate Appearance row, and earlier surface access. Existing themes/icons remain available.
- Open json.site inside Elsepin using a Safari sheet; return with Done, then explicitly Paste and review. No automatic data upload or clipboard reads.
- Consistent import/export action styling and concise help beneath import controls.
