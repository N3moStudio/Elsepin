# Elsepin 2.6.0 — A familiar app, a new identity

Shift is becoming Elsepin. We want a clearer official home and fewer opportunities for repackaged copies to be presented as someone else's original work. Development now lives in a private repository, while official downloads, help and release notes remain public. This makes casual source-based rebranding harder; it does not make copying impossible or erase the licenses and credits of earlier work.

## Changes since the last official Shift release

Baseline: **Shift 2.5.8 (58)**. This draft describes **Elsepin 2.6.0 (59)**. Features already shipped in 2.5.8 are identified separately below.

### A complete Elsepin identity

- Update the app's visible name, Settings, setup and pairing instructions, notifications, Live Activities, helper download wording and exported backup filenames.
- Make **Prism Jumpgate** the default Home Screen icon for a fresh installation. Keep all thirteen icon options and nine themes.
- Finish old-name cleanup in incomplete-backup errors and diagnostic export descriptions.
- Preserve existing bundle identifiers, preferences, keychain services, widget links and backup formats for compatibility. Internal historical identifiers and required third-party notices remain intentionally intact.

### Themes that change more than an accent

- Give Ion a dark olive canvas, opaque panels and bright citron actions, closer to the original visual concept.
- Let themes supply defaults for color mode, solid/glass surfaces, font design and relative text size.
- Add independent, persistent appearance overrides and a reset-to-theme control.
- Replace app-owned translucent navigation/control surfaces when Solid is selected. System-owned menus still follow iOS behavior.
- Keep the map and current session alive during appearance changes.
- Respect accessibility text sizing and Reduce Transparency.

### Refreshed Settings and updates

- Add an appearance card and clearer Settings groups.
- Add a Software updates section with a manual check for official releases.
- Show progress, no-update feedback and useful errors; guard canceled requests and respect server cooldowns.
- Keep automatic checking limited to foreground use, at most once daily. Prereleases are not offered as official updates.
- Point official update discovery to the public Elsepin-Releases repository. A release must actually be published there before the app can offer it.

### Backups and upgrade compatibility

- Export the new appearance preferences and review/import them individually.
- Continue reading older library files and preserve unchecked settings and library selections.
- Retain compatibility identifiers rather than treating the rebrand as a new empty library.
- Export a backup before replacing an installation; different signing/container setups can affect whether iOS preserves its data.

### A new website and official download home

- Launch a responsive website with nine interactive theme previews, thirteen icon choices, setup and privacy pages.
- Serve the site statically without tracking or keep-alive pings.
- Separate private development from public downloads and help.
- Improve the public README with visual artwork, grouped features, limitations and direct website links.
- Preserve the complete historical changelog and add a build register, including failed attempts and subsequent fixes.
- Catalog branding, dependencies and compatibility-sensitive code for future maintenance; retain inherited notices.

### Build and maintenance improvements

- Fix appearance initialization ordering discovered during the first native validation attempt.
- Fix icon-resource validation to understand XcodeGen's grouped paths.
- Simplify the manual workflow to **Build Elsepin IPA**: checks run first, then one downloadable IPA is packaged. Remove the packaging checkbox and separate validation-only download.
- Export public documentation and website assets through explicit allowlists; reject unexpected stale website output.

## Still included from Shift 2.5.8

Teleport, favorites, joystick, walking/cycling/driving routes, route previews, adjustable speeds, stops up to 24 hours, saved routes/places/areas, selective file or pasted-JSON import/export, widgets requiring manual confirmation, Live Activities and Dynamic Island remain available. The earlier tray/joystick interruption fixes, scoped resets, Recently Deleted selection, nine themes and thirteen icons are retained, not newly introduced by this release.

## Experimental features and limits

Find My Devices, Life360 observations and Nearby enter/leave alerts require separate authorized helper setup. Availability, freshness and notification delivery depend on the provider and hosting. A local session indicator cannot confirm every other app's reported location. **Find My People remains unsupported.** Elsepin does not guarantee undetectability or compatibility with every service.

## Validation and publication status

This is a draft, not a published release. Recorded native validation passed **533 automated tests** and compiled the app and extension at source `b5f5b24`. A later wording cleanup passed **32 targeted backup/log tests**. Those results do not certify a newer packaged IPA, real-provider delivery, device appearance, accessibility or battery behavior.
