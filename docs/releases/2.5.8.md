# Shift 2.5.8 — More ways to make it yours

Official release · Build 58 · 26 October 2026

Shift 2.5.8 adds more appearance choices, smoother map controls, simpler cloud setup and optional place alerts. Your existing themes, icons, saved library and full Shift features remain available.

## New themes and icons

- Six additional themes: **Ion, Ember, Abyss, Bloom, Blueprint and Titanium**, each with light and dark colors.
- Four new app icons: **Ion Jumpgate, Titanium Jumpgate, Prism Jumpgate and Ember Switchpath**.
- **Nine themes and thirteen icons in total.** Mix any theme with any icon in **Settings → Appearance**. Your previous selection stays selected.
- Matching colors and simplified marks in widgets and Live Activities. New icons use iOS's automatic Home Screen appearance treatments.
- Icon choices stay disabled while iOS finishes changing the icon, avoiding competing requests.

## Smoother map controls

- Immediate press feedback on key map actions, including Start, Teleport, Pause/Resume, Stop and route review.
- Safer control-tray dragging: canceled or interrupted touches settle back to the existing position. The handle can also be tapped to expand or collapse.
- Joystick movement stops on release, cancellation, backgrounding or when its controls are covered. A fresh touch is required after an interruption.
- Motion respects Reduce Motion and adds no continuous animation or polling loop.

## Simpler cloud setup and optional Nearby alerts

- A smaller setup screen with connection testing, supported-feature detection and the full guide linked under Advanced.
- A refreshed helper website with compact connection cards, a separate place editor, dark mode, scalable text and Reduce Motion support.
- Experimental fixed-place enter/leave rules for selected **Find My Devices** or authorized **Life360 Circle** members.
- Optional repeated or escalating reminders, duration limits, Pause controls and an explicit **Stop this alert** action.
- Opt-in Home Screen Web Push, encrypted helper state, fresh-report checks and confirmation before reporting a boundary crossing. Rules restart paused after a helper restart.

**Provider limits:** Find My People is not supported. Find My Devices, Life360, Nearby and Web Push depend on your own helper, account, permissions and current provider behavior. Free hosting can sleep or lose state. A successful spoofing command does not prove what another app sees; no always-on operation or zero battery use is promised.

## Library and maintenance

- Scoped reset options and bulk selection in Recently Deleted.
- Keep saved routes, areas, favorites, import/export, route drawing/driving and existing widgets.
- Widget taps still only prepare a pin. **Always confirm Teleport/Start manually in Shift**, including during an active session.

## Installation

Install the new IPA over your current Shift installation using the same signing setup. Keep the widget/Live Activity extension. Back up your library first; do not uninstall just to update.

Minimum iOS version: **18**. Device pairing, signing and LocalDevVPN requirements still apply. See the [setup guide](https://github.com/N3moStudio/Shift/blob/main/SETUP.md) and [cloud guide](https://github.com/N3moStudio/Shift/blob/main/docs/CLOUD-GUIDE.md).
